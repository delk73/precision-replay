# Normative Vocabulary Specification

## 1. Domain & Architecture Boundaries

### On-Target Domain (Target)
The constrained execution environment running the primary control loop. The Target is subject to hard real-time execution constraints and shall execute state transitions within deterministic cycle ticks without blocking on host-side transport or allocation overhead.

### Host-Side Domain (Host)
The off-target execution environment responsible for receiving telemetry, executing post-facto state reconstruction, interpolating sequence gaps, and validating state hashes against target run artifacts.

### Telemetry Exhaust
The sequence of non-critical byte payloads generated by the Target's execution loop. Telemetry Exhaust is treated as lossy output; its capture, buffering, or transport failure shall never modify or stall the primary control execution path.

### Ingress Telemetry Stream (Ingress Stream)
The sequence-indexed stream of frame payloads as received by the Host, prior to frame validation, gap detection, or state injection.

---

## 2. Execution & Time Representation

### Deterministic Cycle Tick ($t_k$)
A discrete, monotonically increasing integer counter representing time step $k$ in the primary execution loop. All state updates, frame timestamps, and verification hashes shall bind strictly to cycle ticks rather than wall-clock time.

### Fixed-Point State Transition
A mathematical state transition function computed using integer or fixed-point arithmetic to guarantee bit-exact cross-platform parity between Target and Host execution environments.

---

## 3. Data Structures & Payloads

### State Vector ($S_k$)
The complete, explicit set of state variables required to uniquely define the system state at cycle tick $k$.

### Initial State Seed ($S_0$)
The immutable baseline configuration, calibration matrices, and initial parameters required to initialize the state machine at tick $t_0$.

### Keyframe Snapshot
A self-contained payload containing a complete, uncompressed State Vector ($S_k$). A Keyframe Snapshot allows the Host to establish or re-establish a verified baseline without processing prior historical frames.

### Delta Frame
A telemetry payload containing only inputs, mutations, or quantized state diffs relative to a preceding cycle tick or frame.

### Lockless Ring Buffer
A statically allocated, fixed-capacity circular queue operating on the Target. 

#### Overwrite Policy
When the buffer reaches capacity, the producer write operation shall advance both the write and read pointers simultaneously, overwriting the oldest unread frame slot and dropping that payload to guarantee $O(1)$ non-blocking completion.

---

## 4. Continuity & Verification Events

### Sequence Gap
A discontinuity in frame sequence numbers ($\text{Seq}_k \neq \text{Seq}_{k-1} + 1$) in the Ingress Stream, indicating lost or unbuffered frames between Target and Host.

### State Interpolation
The deterministic Host-side computation of intermediate State Vectors across a Sequence Gap using fixed-point transition models and known control invariants.

### State Hash / Checksum ($H(S_k)$)
A deterministic cryptographic or algebraic digest computed over the State Vector ($S_k$) at tick $k$.

### Desynchronization Fault (Desync)
A verification failure triggered when the Host-reconstructed state hash does not match the Target-generated state hash ($H_{\text{host}}(S_k) \neq H_{\text{target}}(S_k)$).
